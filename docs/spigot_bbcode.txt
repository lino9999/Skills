[SIZE=5][COLOR=#ff00ae][B]⚡ Why Choose Skills?[/B][/COLOR][/SIZE]

Are you tired of bloated RPG plugins that require tons of external dependencies, crash on server restarts, or lag your main tick loop?
[B]Skills[/B] is a clean, modern, ground-up recreation of the classic RPG skill leveling experience:
[LIST]
[*][B]Zero Dependency Bloat[/B]: Runs 100% standalone. No proprietary libraries or extra plugin requirements!
[*][B]Folia & Paper Native[/B]: Built using multi-threaded asynchronous scheduling and non-blocking SQLite database storage.
[*][B]Ultra Lightweight (130 KB)[/B]: Up to 40x smaller and faster than legacy alternatives.
[*][B]9 Dynamic Skills[/B]: Mining, Woodcutting, Farming, Combat, Armory, Fishing, Alchemy, Enchanting, and Exploration.
[*][B]9 Real-Time Attributes/Stats[/B]: Defense, Strength, Speed, Health, Crit Chance, Crit Damage, Ferocity, Wisdom, and Attack Speed.
[*][B]26 Passive Effects[/B]: Bleed DoT, ore multiplication, crop harvesting boosts, dodge negation, durability auto-repair, and boss defense.
[*][B]Persistent Action Bar HUD[/B]: Real-time health, defense, strength, speed, and mana right above player hotbars!
[*][B]Holographic Damage Numbers[/B]: Crisp modern damage and critical strike indicators using native text displays.
[*][B]Native PlaceholderAPI Hook[/B]: Built-in support for all `%skills_*%` PlaceholderAPI placeholders across scoreboards, tablists, and holograms!
[/LIST]

[SIZE=5][COLOR=#ff00ae][B]💻 Commands & Permissions[/B][/COLOR][/SIZE]
[CODE]
Player Commands:
/skills                  - Open the skills overview GUI (skills.menu)
/stats                   - Open your attributes GUI (skills.stats)
/skills rank             - View the top players leaderboard (skills.rank)
/skills hud              - Toggle the HUD actionbar on/off (skills.hud)
/skills audio            - Toggle skill XP gain sounds (skills.audio)

Administrator Commands:
/skillsadmin reload      - Hot-reload all configurations (skills.admin.reload)
/skillsadmin add <player> <skill|attribute|mana> <amount> - Grant XP/Attributes (skills.admin.add)
/skillsadmin set <player> <skill|attribute> <value>       - Set tier/bonus (skills.admin.set)
/skillsadmin wipe <player|all>                            - Wipe progression (skills.admin.wipe)
/skillsadmin sync [player|all]                            - Sync attributes (skills.admin.sync)
[/CODE]

[SIZE=5][COLOR=#ff00ae][B]🔌 PlaceholderAPI Support[/B][/COLOR][/SIZE]
[LIST]
[*][COLOR=#3498db]%skills_<skill>_level%[/COLOR] - Current level
[*][COLOR=#3498db]%skills_<skill>_level_numeral%[/COLOR] - Roman numeral (e.g. XIV)
[*][COLOR=#3498db]%skills_<skill>_xp%[/COLOR] - Current progress XP
[*][COLOR=#3498db]%skills_<skill>_required_xp%[/COLOR] - Next level requirement
[*][COLOR=#3498db]%skills_<skill>_progress%[/COLOR] - Percentage progress (e.g. 74.2%)
[*][COLOR=#3498db]%skills_<stat>%[/COLOR] - Total stat value
[*][COLOR=#3498db]%skills_total_skill_level%[/COLOR] - Total skill level sum
[*][COLOR=#3498db]%skills_mana%[/COLOR] & [COLOR=#3498db]%skills_mana_limit%[/COLOR] - Mana points
[/LIST]
